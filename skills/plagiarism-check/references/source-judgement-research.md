# Source judgement brief: research essay additions

Appended to `source-judgement.md` for research essays. Modifies Checks 1, 2 and 3.

## Check 1 addition: technical terminology

Terms that appear in both source and draft are not overlap if they are the field's standard vocabulary, the only possible terms for the concept. Look at the source's own usage: if it treats the term as established (no definition, no citation for the term), it is probably field-standard; if it defines or attributes the term, it is probably specific to the source. When the profile key `common_terms` names a file, terms listed there are field-standard. Flag only non-standard multi-word phrases specific to this source's formulation.

## Check 2 addition: synthesis for research essays

Synthesis needs more than using a source to support a claim: the writer shows how the source fits into the wider conversation, where it agrees, complicates or contradicts other cited sources. A paragraph that uses one source without placing it against other scholarship may still be summary even if the claim is the writer's.

## Check 3 addition: framework attribution

Attributing a framework to its originator is expected even for familiar concepts. The frameworks a field credits are read from the writer's field page (profile key `field_bank`); this skill names none. Flag the absence of attribution for a framework on that page even when it seems like common knowledge; "it is well known that…" is not attribution. With no field page, apply Check 3 only to frameworks the source itself attributes to a named originator.
