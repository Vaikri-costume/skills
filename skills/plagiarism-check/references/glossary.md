# Glossary — plagiarism-check

Terms this skill uses. `$RUN` is the run folder; `[QUOTE-UNMATCHED]` marks a finding whose quote is not in the draft. Verdict labels: upheld, disputed, ambiguous, unaddressed (`challenger-synthesis-rules.md`).

| Term | Definition |
|---|---|
| `Check 1/2/3/5/6` | the judgement checks: overlap matches, synthesis versus summary, framework origin, paraphrase distance, claim fidelity |
| `citation-check` | default mode: compares the draft with its cited sources |
| `claim fidelity` | what a source's text says about a claim the draft cites it for: supports, partly supports, contradicts, not found in the source text, not checked |
| `Clean / Fix / Not found / Review` | the four outcomes for a reference entry |
| `frankenstein` | flag for an entry whose identifier or title leads to a different work, so its parts may come from different works |
| `full-scan` | mode that compares the draft with every source page in the project |
| `judgement agent` | the read-only agent that judges one source |
| `overlap.json / audit.json / quotes.json` | deterministic outputs, rendered but never re-judged |
| `patch log` | proposed corrections with original, proposed value, source and reason; never applied by the skill |
| `PlagSource-<slug>-<run>` | name of the judgement agent for one source |
| `reference-check` | mode that checks the reference list against public indexes and, where text is available, against the claims |
| `short-match` | four to five identical words with three or more content words; weak evidence |
| `status ladder` | see `acceptable-use.md` |
| `verbatim-run` | an identical run of words outside quotation marks, at least the minimum length (`acceptable-use.md`) |
| `Weight` | poor-academic-practice, minor or major |
