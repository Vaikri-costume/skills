# Glossary — review-writing

This file lists the terms this skill uses.

Terms used throughout: `$RUN` (temp run folder), A/B pair (two read-only agents with identical prompts), HIGH / UNVERIFIED (analysis confidence: both agents / one agent flagged it), nine verdict labels (see `challenger-synthesis-rules.md`), `[QUOTE-UNMATCHED]` (the quote is not in the draft).

## Skill-specific terms

| Term | Definition |
|---|---|
| `cross-domain merged` | a finding flagged in two domains on the same passage |
| `Element` | which Toulmin part an argument finding concerns |
| `feed up / back / forward` | where the writing is going / how it is going / where to next |
| `field bank` | the writer's private pages on what a field expects; read at run time, never held in the skill |
| `layer` | foundation (claim and question), structure, paragraph, sentence: the order findings are reported in |
| `lens` | one of three blind readers (audience, rigour, premise) who return questions, not verdicts |
| `promise` | what the opening says the draft will do; checked against where it is delivered |
| `revision-diff` | mode that reports whether earlier comments were addressed in a revised draft |
| `severity anchors` | descriptive meanings for High, Medium, Low |
| `source status` | bibliography-mode word for what was checked about an entry: not checked, identity matched, text checked, supports, partly supports, contradicts |
| `verdict table` | rubric criteria in the rubric's order with met, partly, not met or not found in the draft |
| `warrant` | the bridge that makes the grounds support the claim |
