# Draft mode (only when the writer names it)

For work in progress: an outline, a half-built section or notes toward an argument. The aim is direction, not judgement. This mode gives no verdict, no severity, no findings list and no strengths ranking. It asks questions the writer can answer from their own material.

Run it single-pass inline (no A/B pairs, no challengers). Read the whole text first.

## What to produce

1. **What I read the draft as heading towards:** the claim or aim as you read it, one quoted phrase, and where you could not tell.
2. **Questions on direction**, each anchored to a quoted line and tagged with the layer it concerns (foundation: claim and question; structure: order and sections; paragraph: what each paragraph is for; sentence: only if a sentence blocks understanding):
   - what the quoted line commits the writer to;
   - what the writer would need to show for the next step to follow;
   - where two quoted lines pull in different directions;
   - what a sceptical reader would ask at this point.
3. **What is already doing work:** quote the lines that carry the direction, so the writer keeps them.

## Rules

- Every question ends in a question mark and can be answered by the writer from their own sources or thinking. No question hides an instruction ("have you considered adding X?").
- Never supply content: no claim, thesis, topic sentence, outline, example, source or wording. Do not name a source the writer has not named.
- Questions are ordered by layer (foundation first), the most consequential first within a layer. No limit on how many; ask what the text raises.
- No numeric or word grades, and the Hard rules in SKILL.md otherwise apply.
- Draft mode says nothing about errors; it is not proofreading.
