# Glossary — proofread

See also: [`ccvw-glossary.md`](../../skill-creator-ccvw/references/ccvw-glossary.md) for the shared CCVW terms (cluster, FIX, STRENGTHEN, tier, etc.). This file lists only skill-specific terms.

Shared terms for the four writing skills: `$RUN` (temp run folder), A/B pair (two read-only agents with identical prompts), HIGH / UNVERIFIED (analysis confidence: both agents / one agent flagged it), nine verdict labels (see `challenger-synthesis-rules.md`), `[QUOTE-UNMATCHED]` (the quote is not in the draft).

## Skill-specific terms

| Term | Definition |
|---|---|
| `Check 1–5` | grammar, typos, British spelling, consistency, register quality |
| `compound finding` | a Check 3 and a Check 4 finding for the same word merged into one entry |
| `matched-incorrect` | unrecognised term that matches a terms-file entry in a wrong form; reported as a Check 3 finding |
| `migration suggestions` | matches found only in other or global terms files, offered to the writer for the report |
| `near-matched` | unrecognised term close to a terms-file entry; reported as a Check 3 finding tagged UNVERIFIED |
| `quick wins` | the report section of fixes that are simple and safe to apply first |
| `surface / consistency / register agents` | the three read-only agent pairs |
| `terms file` | markdown list of canonical project terms, one `- term` per line |
| `unresolved` | unrecognised term with no terms-file match; put to the writer in one question |
