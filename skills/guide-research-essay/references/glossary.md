# Glossary — guide-research-essay

See also: [`~/.claude/skills/skill-creator-ccvw/references/ccvw-glossary.md`](../../skill-creator-ccvw/references/ccvw-glossary.md) for the shared CCVW terms. This file lists only skill-specific terms.

## Skill-specific terms

| Term | Definition |
|---|---|
| `AI-rules file` | The user's own markdown file listing, per assessment, what AI help is allowed; read fresh on every use |
| `built-from trace` | One line per paragraph naming the user's notes that paragraph uses |
| `evidence map check` | Marking each outline point as supported, stronger or wider than its note, or no support found |
| `flagged, not changed` | A difference listed for the user to resolve; the skill never corrects it |
| `gap marker` | A marker the user writes where their notes run out; listed, never filled |
| `gate` | Step 0: read the AI-rules file, classify the use, stop where the file says no AI or says nothing |
| `hardened hedge` | A claim written more firmly than its note, such as "suggests" becoming "shows" |
| `stuck prompt` | A question that helps the user begin; never a sentence, heading or opening |
| `brief check` | Outline mode: the user says what the brief requires and the claim is checked against the brief's own text |
| `draft mode` | Mode that checks a paragraph or section the user already wrote against their notes |
| `exactness check` | Draft check comparing numbers, names, dates and quotes with the notes; differences are listed, none corrected |
| `gap list` | Draft check listing every open marker the user left, in order, with the note each depends on |
| `link check` | Draft check quoting each "therefore", "because" or "however" that the notes do not state |
| `outline mode` | Mode that checks an outline the user wrote against the brief and their notes |
| `position prompt` | Outline question asking where in the outline the position is stated; never a request for a new thesis |
| `reading in general` | Reading mode with no named question |
| `reading for a research question` | Reading mode run against a question the user names |
| `study support` | Gate category for reading help, as opposed to feedback on the user's own work or generating |
| `use record` | One row for the user's use log naming the tool, what it did and the acknowledgement sentence the rules file gives |
