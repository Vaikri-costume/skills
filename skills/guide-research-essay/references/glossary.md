# Glossary — guide-research-essay

See also: [`~/.claude/skills/skill-creator-ccvw/references/ccvw-glossary.md`](../../skill-creator-ccvw/references/ccvw-glossary.md) for the shared CCVW terms. This file lists only skill-specific terms.

## Skill-specific terms

| Term | Definition |
|---|---|
| `AI-rules file` | The user's own markdown file listing, per assessment, what AI help is allowed; read fresh on every use |
| `built-from trace` | One line per paragraph naming the user's notes that paragraph uses |
| `evidence map check` | Marking each outline point as supported, stronger or wider than its note, or no support found |
| `flagged, not changed` | A difference listed for the user to resolve; the skill never corrects it |
| `gap marker` | A marker the user writes where their notes run out; listed, never filled |
| `gate` | Step 0: read the AI-rules file, classify the use, stop where the file says no AI or says nothing |
| `hardened hedge` | A claim written more firmly than its note, such as "suggests" becoming "shows" |
| `stuck prompt` | A question that helps the user begin; never a sentence, heading or opening |
