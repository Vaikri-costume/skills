# Glossary — ai-detection-check

See also: [`ccvw-glossary.md`](../../skill-creator-ccvw/references/ccvw-glossary.md) for the shared CCVW terms (cluster, FIX, STRENGTHEN, tier, etc.). This file lists only skill-specific terms.

Shared terms for the four writing skills: `$RUN` (temp run folder), A/B pair (two read-only agents with identical prompts), HIGH / UNVERIFIED (analysis confidence: both agents / one agent flagged it), nine verdict labels (see `challenger-synthesis-rules.md`), `[QUOTE-UNMATCHED]` (the quote is not in the draft).

## Skill-specific terms

| Term | Definition |
|---|---|
| `Pattern+Voice` | a pattern finding and a voice finding on the same passage, merged |
| `baseline` | the writer's own earlier texts, used for a comparison; needs about 1,000 words |
| `descriptive metrics` | numbers with no thresholds or colour ratings |
| `hedging anchors` | three confirmed sentences (should hedge, should not, ambiguous) |
