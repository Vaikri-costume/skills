# Script contract reference

Contents: non-zero exit handling · broken ledger · script index.

SKILL.md describes each script's success path. For a non-zero exit, classify and act:

| Script | Non-zero exit | Action |
|---|---|---|
| `prepass_run.py` | 0 always carries a status JSON (`converged` / `needs-record` / `needs-fix`; findings are NOT an error); 1 = pipeline error (a sub-script failed, or a detector crashed: `detector_errors` on stderr); 2 = `--target` is not a directory | 1: read the stderr JSON; a crashed detector must be fixed before Prepass can converge. 2: fix args, re-run |
| `check_decisions.py` | 1 = a fixer's decisions have a problem (an empty address, an unknown decision word, a kind prefix that differs from the decision, banned dismissal vocabulary, a FIX without non-empty `Siblings:`, `Bound:`, `Claims:` and `Blocks:` lines in its `closure` list, a duplicate, missing or foreign cluster, or a final message that is not decisions JSON; listed in the JSON on stdout); 2 = invocation error or an unreadable transcript | 1: `SendMessage` the same fixer the listed problems, ask it to re-emit its decisions, and re-run the check before the next batch or fill-address. 2: fix the path |
| `ledger_cascade.py --mode fill-address` | 1 = a non-canonical address (`FIX:` instead of `FIX (`), banned dismissal vocabulary in an address, a cluster decided in two fixer transcripts, no entry for a FIX decision's cluster in `--blast-json`, a TOKEN-BLAST entry with no token ("TOKEN-BLAST cluster has no token in --blast-json"), a TOKEN-BLAST FIX whose `touched_files` is empty, or a TOKEN-BLAST FIX has uncovered sites (a pipe character or newline inside an address is not rejected: the script rewrites it to a slash or a space); 2 = ledger not found, `--phase` missing, a FIX decision arrived without `--skill-root`/`--blast-json`, the `--blast-json` file is unusable (`-`, not found, or not valid JSON), a `--fixer-transcript` cannot be read or its final message is not valid decisions JSON ("cannot read decisions from fixer transcript"), stdin is not valid JSON, or no `--fixer-transcript` yields any decision (every one has an empty or absent `decisions` list; nothing is written, where a partial set still auto-pauses the undecided clusters) | 1: re-emit the offending decision (non-canonical or banned wording), or cover the listed uncovered sites (or pass `--allow <files>` with a stated reason), and re-run. 1 with "has no token in --blast-json": fix_blast.py could not extract the cluster's token; add `"token": "<the name the fix changed>"` to that entry of the blast file (what `fix_blast.py --token` supplies) and re-run. 1 for an empty `touched_files`: `SendMessage` the same fixer to re-emit that decision listing every file it edited, then re-run. 2 with "cannot read decisions from fixer transcript" (or "stdin is not valid JSON"): check that the path is the fixer's own transcript; if it is, the fixer's final message is not decisions JSON: `SendMessage` the same fixer to re-emit the `{"decisions": [...]}` object, then re-run. 2 with "no fixer transcript yielded any decision": check that the paths are the fixers' own transcripts, `SendMessage` each fixer to re-emit its decisions, then re-run. 2 naming `--blast-json` (missing, `-`, not found, or not valid JSON): the orchestrator-written blast file is at fault, not the fixer; rewrite it from the blast array the tier's cluster-stage script printed and re-run. Any other 2: broken ledger or missing `--phase`, stop |
| `code_review_run.py` | 2 = invocation error (bad `--target` or `--scope`, a missing template or lens body); a missing ledger at the marker write is an uncaught `FileNotFoundError` that exits with status 1 ("Broken ledger" below); it has no other non-zero exit | exit 2: fix args or restore the missing file, re-run; status 1: stop (broken ledger) |
| `code_review_collect.py` | 2 = invocation error; 1 = contract violation and/or incomplete coverage (reported in one pass), or an agent aborted at the pre-flight gate because staged files are missing (`aborted_agents` on stderr). A contract violation includes a malformed or incomplete ISSUE block and an ISSUE block count other than the declared `No of issues found:: N` (more blocks than declared is a violation to re-emit, never "drop the first blocks") | 1 with `aborted_agents`: hard unrecoverable error, stop and report the missing paths (`references/recovery.md` "Hard unrecoverable errors"). Any other 1: apply contract recovery (`references/dispatch.md`) before re-running |
| `cluster_enforce.py` | 1 = a verified flag was dropped, an unverified (extra) or duplicated flag id appears in the clusters, a blast group split, or `ledger_cascade.py cluster` / fixer-prompt staging failed; 2 = invocation error (bad `--target`; `--verified-flags` not found, not valid JSON (or invalid stdin with `-`), or not a JSON object or array; `--clusters` not found, not valid JSON, or not a JSON object or array) | 1: fix the clusters file or the cause named on stderr, re-run (cluster ids in it are placeholders; the script renumbers them to continue the round). 2: fix args or input; for `--verified-flags`, point it at the collector's `cr-verified-<N>-<RUN_TIMESTAMP>.json` output (SKILL.md Code-review) |
| `doc_lint.py` | 2 = `--target` is not a directory or `--checks` names an unknown check | fix args. Exit 1 is never emitted; findings are advisory and the orchestrator decides which are real |
| `append_ledger.py close-round` | 1 = no FIX row (and not `--converged` / `--strengthen-only`), an open pause, or a row of the round still PENDING (`pending_rows` on stderr); 2 = ledger not found | 1: resolve the cause (for PENDING rows, run the fix-recording step for their phase); when every finding was a legitimate STRENGTHEN (no FIX row can exist), pass `--strengthen-only "<reason naming the how-to-fix.md case>"`. 2: stop |
| `append_ledger.py begin-round` / `append_ledger.py options` | begin-round 1 = the round is already closed; 2 = bad `--set` (not `key=value`, an unknown key, including a legacy v1 key, or a `rounds-budget` / `max-rounds` / `run-start-round` that is not a positive integer; nothing is written), a missing `--target`, or the ledger's `target::` line records a different target than `--target` (two targets share the basename; nothing is written), or for `options` the ledger is not found | 1: begin the next round instead. 2 for a different recorded target: stop and tell the user that `<ledger>` already belongs to the recorded target, and give this target a ledger path of its own. Any other 2: fix args |
| `append_ledger.py append` | 1 = the row is rejected (a pipe character or newline in a cell, banned dismissal vocabulary, an address not starting with a kind, a FIX row without `--blast-radius-status`, an unknown `--phase`, flag ids on a pause-resolving row, a malformed `--cluster`, or a `--cluster` id the round already holds; nothing is written); 2 = ledger not found | 1: correct the named field and re-run (for a reused cluster id, use the next free id the message names). 2: stop |
| `append_ledger.py check-pauses` | 1 = at least one ORCHESTRATOR-PAUSE / USER-PAUSE row is unresolved (listed in the JSON on stdout); 2 = ledger not found | 1: resolve each listed pause (SKILL.md check-pauses step) and re-run until it exits 0. 2: stop |
| `append_ledger.py gate` | 1 = the round gate says stop (`round-cap`, `budget-exhausted`, `stalled`); 2 = ledger not found | 1: not an error: report a stop that is NOT convergence. 2: stop |
| `append_ledger.py verify-auditability` | 1 = a flag id appears in more than one row of the round, or an `--expect` set differs from the flags in the ledger (`duplicates`, `missing_from_ledger`, `unexpected_in_ledger` in the JSON on stdout); 2 = ledger not found | 1: report the listed flag ids. 2: stop |
| `post_fix_gate.py` | 0 = pass; 1 = blocking problems (`check`: the JSON `problems` list of `{file, line, kind, problem}`, `kind` one of `lint:<check>`, `unresolved-path`, `unresolved-flag` (a CLI flag on a touched line that the script the line is in or names does not register), `unresolved-exit-code`, `unresolved-identifier`, `new-behaviour`, `syntax` (a touched non-test .py file that no longer parses; line 0, the whole file), `block-reread` (a rewritten doc block of 3 or more lines, at least 2 and 30% changed, that no `Blocks:` closure line of a `--fixer-transcript` decision names; the untouched lines of such a block are also lint- and name-checked) or `stale-sibling` (a file, flag or identifier the batch removed that a line of the target still names); the non-blocking `siblings` list (at most 15 distinctive terms of 1 to 12 untouched lines each) with `siblings_omitted` and the `rewritten_blocks` list are printed on 0 and 1; `merge-check`: the trees differ; `causes`: one stderr line per problem file, a `--write` or `--check` file it cannot read, a `--write` file with no `gate-exit2` marker block, or a `--check` table that is missing or differs; `causes` never exits 2); 2 = unreadable input for `snapshot`, `check`, `merge-check` and `survival` (a missing directory, an in-scope target file that cannot be read as UTF-8, an unreadable or malformed snapshot, `--baseline-lint` file (including a dict holding only one of `doc_lint` / `cascade`) or ledger, a lint run that failed, or a `survival --row` matching no ledger row or several) | `check` 1: send the problems to the same fixer (SKILL.md "Post-fix gate"); `new-behaviour` problems and any still listed after 2 inner passes become ORCHESTRATOR-PAUSE, except a behaviour-preserving refactor, re-checked with `--accept-new-behaviour <file>:<kind>` (`<kind>` = the node kind in the problem text, `<kind> count N -> M`: `raise`, `return`, `exit`, `if`, `for`, `while`, `try`, `ifexp` or `boolop`) and recorded in the ledger as a row with the batch's phase and address `FIX (<file>: <the refactor>)`. `merge-check` 1: merge the listed files into the source or report them. `causes` 1, per stderr line: `cannot read`: fix the path and re-run; `missing or differs`: run the `causes --write <path>` the line names; `no ... block to replace`: the file is not one of the two docs that carry the table (SKILL.md, `references/script-contract.md`), so pass the right path. 2: unreadable input; the stderr JSON carries `cause` and `remedy`, and the table under this one lists every cause (`post_fix_gate.py causes`) |

**Broken ledger:** if the ledger is unreadable or missing where it must exist, stop and tell the
user the path and the failure. A tier script that reaches its marker write with no ledger at the
path exits 1 with `FileNotFoundError: ledger not found, cannot write in-flight marker` on stderr
(`ledger_common.write_marker`); this is that case.

## Script index

- `scripts/prepass_run.py`: Prepass entry (sweep, cluster, blast, write PENDING rows, stage one fixer prompt per batch).
- `scripts/code_review_run.py`: Code-review entry; decides the review scope (full or changed files), stages the all-lens reviewer prompt and writes the scope record.
- `scripts/code_review_collect.py`: coverage gate (over the recorded scope), contract check, flag numbering and advisory blast groups (clustering and ledger rows are `cluster_enforce.py`'s).
- `scripts/cluster_enforce.py`: no-drop and blast-split gates; the only path to Code Review PENDING rows; stages one fixer prompt per batch.
- `scripts/check_decisions.py`: checks each fixer's decisions before fill-address records them.
- `scripts/ledger_cascade.py`: PENDING rows (`cluster`) and the ledger update after a fixer (`fill-address`).
- `scripts/append_ledger.py`: ledger primitives: `begin-round`, `append`, `close-round`, `check-pauses`,
  `verify-auditability`, `options`, `gate`.
- `scripts/ledger_common.py`: shared library (not a CLI): the ledger format and its parsers, the run options and their migration, the frozen-interface rule, and the tier-script steps both tiers share (auto-pause rows, fixer batching and prompt staging, reading a fixer's decisions).
- `scripts/stage_cold_prompts.py`: prompt staging utility.
- `scripts/assemble_fix_prompt.py`: builds the fixer prompt (called by `prepass_run.py` and `cluster_enforce.py`).
- `scripts/fix_blast.py`, `scripts/check_fix_radius.py`: blast-radius classification and the
  mechanical closure check.
- `scripts/doc_lint.py`: advisory fixed doc lint run after a Code Review fixer (twelve checks, listed in its docstring; the last three, `fix-narration`, `raises-no-raise` and `unused-param`, read only .py files outside `tests/`; `usage-flags`, `exit-codes`, `doc-count` and `retired-term` also read scripts).
- `scripts/coverage_check.py`, `scripts/inscope.py`: read-coverage check and the in-scope file set.
- `scripts/post_fix_gate.py`: the post-fix gate (`snapshot` / `check` around each fixer batch, `merge-check` of an audited copy, `survival` records); tests in `tests/test_post_fix_gate.py`.
- `scripts/render_ledger.py`: standalone ledger renderer.
- `scripts/cleanup_tmp_prompts.py`: scoped removal of staged tmp files.
- `cascade_sweep.py`, `cluster_prepass.py` (skill root): the detector sweep (`--level prepass` gates,
  `--level advisory` never does) and the prepass clusterer; `prepass_run.py` runs both (and imports
  `cluster_prepass` for the finding signature), and `fix_blast.py` reads the clusterer's output.

## post_fix_gate.py exit 2, by cause

Generated from `EXIT2` in the script (`post_fix_gate.py causes --write references/script-contract.md`); do not edit by hand.

<!-- gate-exit2:begin -->
| Cause | Observable | Remedy |
|---|---|---|
| not-a-directory | `--target is not a directory: <path>` (`snapshot`, `check`) or `not a directory: <path>` (`merge-check`) | fix the path and re-run |
| unreadable-target-file | `cannot read <path>: ...` (an in-scope target file that is not UTF-8 text) | fix that file and re-run |
| snapshot-unusable | `unreadable snapshot <path>: ...` (the `--snapshot` path names no file, or the file is not a snapshot), or `lint data is not a JSON object` / `<source> lint data is not a JSON object` with this `cause` (the snapshot's stored `lint` field is malformed) | the batch's baseline is lost: take no new snapshot after the batch has edited the target, report the batch as unchecked and `SendMessage` the fixer to re-emit the decision of each of its clusters as `ORCHESTRATOR-PAUSE (post-fix gate: snapshot missing or unreadable)` |
| lint-run-failed | `<script> printed no JSON ...`, `<script> exited <N>: ...` or `lint data is not a JSON object`, printed by `check` (`doc_lint.py` or `cascade_sweep.py` failed) | report the batch as unchecked and `SendMessage` the fixer to re-emit the decision of each of its clusters as `ORCHESTRATOR-PAUSE (post-fix gate: lint run failed)` |
| snapshot-lint-failed | the same texts, printed by `snapshot` (before the batch is dispatched) | do not dispatch the batch: leave its transcript out of the fix-recording step so fill-address records its clusters as ORCHESTRATOR-PAUSE |
| baseline-unusable | `unreadable --baseline-lint <path>: ...` or `<source> lint data is not a JSON object` (including a dict holding only one of `doc_lint` / `cascade`) | fix that file and re-run (SKILL.md's commands never pass `--baseline-lint`) |
| ledger-unreadable | `unreadable ledger <path>: ...` (`survival`) | stop ("Broken ledger" in `references/script-contract.md`) |
| survival-row-ambiguous | `--row <id> matches <N> ledger rows (pass --round)`, N above 1 (`survival`) | re-run with the right `--round` |
| survival-row-missing | `--row <id> matches 0 ledger rows` (`survival`) | correct `--row` or `--round` and re-run |
<!-- gate-exit2:end -->
